# Invest Flow

Русско-английский маркетплейс девелоперских проектов на ранней стадии. В стартовой версии доступны поиск, фильтры и подробные карточки трёх демонстрационных проектов. Основные разделы — «Инвесторам», «Девелоперам» и Premium.

## Публикация в Vercel

Импортируйте репозиторий в Vercel. Корневая папка — корень репозитория. Настройки содержатся в `vercel.json`. Команда сборки — `npm run build`, выходная папка — `dist`. Стартовая версия собирается без переменных окружения. Собственного домена для первого запуска не требуется.

## Локальный запуск

Используйте Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Для просмотра собранного сайта выполните `npm run build`, затем `npm run preview`.

## Аккаунты и публикация объявлений

Когда понадобится приём реальных проектов, создайте отдельный проект Supabase для Invest Flow.

1. Выполните `supabase/schema.sql` в SQL Editor. Схема задаёт таблицы объявлений и заявок на Premium с политиками доступа.
2. В Authentication включите вход по email. Укажите адрес сайта в Site URL и добавьте полный адрес страницы `/account` в список разрешённых URL перенаправления. Для писем посетителям настройте почтовый сервис в Supabase.
3. В Vercel задайте `VITE_SUPABASE_URL` и публичный `VITE_SUPABASE_PUBLISHABLE_KEY` по образцу `.env.example`. В клиентском приложении используется только публичный ключ.
4. Выполните новый деплой. Вход осуществляется по одноразовой ссылке. После входа пользователь возвращается к начатому размещению или заявке.

Каталог показывает примеры сразу после установки. В режиме без базы разработчик может заполнить и скачать карточку проекта. После подключения базы опубликованные объявления доступны посетителям каталога. В опубликованной карточке отображается контактный email, который указал девелопер.

Premium принимает заявки на ранний доступ после подключения базы. Цена и приём платежей пока не заданы.
